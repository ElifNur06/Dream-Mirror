# Rüya Aynası (Dream Mirror) 🌙

Rüya Aynası, kullanıcıların rüyalarını dijital olarak kaydettikleri, yapay zeka ile analiz ettirdikleri ve rüya karakterleriyle etkileşime girebildikleri kapsamlı bir kişisel gelişim ve günlük uygulamasıdır.

## 🚀 Özellikler

- **AI Analiz:** Gemini AI ile rüya metinlerinin mistik, psikolojik veya İslami bakış açılarıyla yorumlanması.
- **AI Görsel Üretimi:** Rüya içeriğine uygun, tarzı ayarlanabilir (Cyberpunk, Yağlı Boya vb.) benzersiz görsellerin anlık üretimi.
- **Kabus Kalkanı:** Kabus gören kullanıcılar için güven verici, terapötik ve pozitif yönlendirmeler içeren özel mod.
- **Rüya Sözlüğü:** Binlerce sembolün anlamını içeren arama motoru.
- **Karakter Sohbeti:** Rüya karakterleriyle etkileşim ve sohbet geçmişi kaydı.
- **Hikayeleştirme:** Rüya metninden sürrealist hikayeler oluşturma.
- **İstatistiksel Analiz:** Geçmiş rüya verilerinden ruh hali ve sembol analizi.
- **Sesli Etkileşim:** Sesli komut girişi (STT) ve yapay zeka seslendirmesi (TTS).
- **Çoklu Dil Desteği:** Türkçe ve İngilizce dil desteği.

## 🎨 Tasarım Kimliği (UX/UI)
Uygulama, estetik ve sürükleyici bir deneyim için **"Glassmorphism"** (buzlu cam) tasarım dilini benimsemiştir. Bu görsel kimlik, rüya dünyasının soyut ve gizemli yapısıyla örtüşen, modern ve derinlik hissi veren bir arayüz sunar.

## 🛠 Teknik Altyapı

### Teknoloji Yığını
| Kategori | Teknoloji / Kütüphane |
| :--- | :--- |
| **Framework** | Flutter (Dart) |
| **Backend** | Python (Flask) |
| **Veritabanı** | SQFlite (SQLite) |
| **Yapay Zeka** | Google Gemini API |
| **Ses / Konuşma** | speech_to_text, flutter_tts |
| **PDF İşleme** | pdf, printing |

### Sistem Mimarisi
Uygulama, veri akışını optimize eden modüler bir yapıya sahiptir:
- **Veri Katmanı:** SQFlite (Yerel DB) ve API veri akışı.
- **Veri Taşıma (Migration):** Versiyon 2 güncellemesiyle verilerin dinamik evrimi (ALTER TABLE).
- **Mantıksal Katman:** Hata yönetimi (mounted kontrolleri, try-catch blokları).
